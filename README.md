# Енот делает ремонт

Одностраничный адаптивный сайт для Instagram-проекта **@enot_delaet_remont**.

## Что внутри

- главный экран с позиционированием проекта;
- блок популярных переделок;
- шпаргалки по ремонту;
- блок о блоге;
- CTA с переходом в Instagram;
- адаптация под телефон и ПК;
- лёгкие анимации появления блоков.

Сайт сделан на чистых HTML/CSS/JS и подходит для публикации через GitHub Pages.
